# Screen comparison

This document covers roadmap Phase 7, "compare every screen with `Research/Screenshots/`". The comparison was made on 2026-10-11 (commit 68d89f61), and most of its findings were fixed directly afterwards. Every item was rechecked against `origin/master` at 64bf172d on 2026-10-12, with fresh probe pictures of the port's screens. The document records the current status of each item and the work that remains. It is a reference only: nothing in it changes the game.

In-game messages are covered by `Research/STRINFO message audit.md`. This document covers what is on screen: displays, labels, layout and the flow of each screen.

## Sources

- **The original:** `Research/Screenshots/` (259 EGA pictures in 19 folders). Where the screenshots run out, the decompiled original ([s-macke/starflight-reverse](https://github.com/s-macke/starflight-reverse), `starflt1-out/overlays/`) shows what a screen does: `ENGINEER.c` (Damage and Repair), `NAVIGATR.c` (shields and weapons), `ANALYZE-OV.c` (Analysis), `HYPERMSG-OV.c` (hyperspace messages), `OP-OV.c` (Operations), `DAMAGE-OV.c` (combat damage), `LAUNCH-OV.c` (launch), `CAPTAIN.c` (the Captain's menu and Log Planet), `MAP-OV.c` (the starmap), `COMBAT-OV.c` (combat), `DPART-OV.c` (the Black Egg), `GAME-OV.c` (the game options, saving and the Interstel Police warning) and `data.h` (the bank's transaction names).
- **The port:** pictures rendered by the headless probe with a graphics device (`DevTools/HeadlessProbe/probe.ps1 -Scenario screenpictures -Graphics` and `starport-screenpictures`): 12 flight screens and 8 Starport rooms, written to `Logs/screen-pictures/` (not committed). Since 2026-10-13 there are also `surfacepictures` (the landed ship and the terrain vehicle screens) and `bridgepictures` (the flight scene's docking bay, Medical, Communications and the launch), and `starport-screenpictures` continues into each room's other screens (29 pictures). Later the same day came `flightpictures` (the Science and Navigation menus, the save panel, combat, the starmap, Log Planet, the descent and the Black Egg countdown; 20 pictures in `Logs/screen-pictures/flight/`) and `intropictures` (the five Intro pages, in `Logs/screen-pictures/intro/`). Where a screen has no picture, the port side is taken from the code.

Out of scope: art style, resolution, colours, fonts and 3D models.

## Labels

- **Status:** FIXED (by the PR named), OPEN, PARTLY (with what remains), NOT A DEFECT, DECIDED (a design decision), PROBE (a gap in, or an artifact of, the probe's pictures rather than the game).
- **Area:** GAMEPLAY (what the game logic does or writes) or UI KIT (the labels, layout and look of the console and the panels, which belong to the UI kit work). An item marked UI KIT is handled by that work and only recorded here.
- **Evidence:** CONFIRMED (seen in a picture or in the code on 2026-10-12), INFERRED (one link unverified, and named), HYPOTHESIZED.
